## Contenido del repositorio

### `datos/`
- `geojson/` — Capas vectoriales en formato GeoJSON
- `shapefiles/` — Capas vectoriales en formato Shapefile

### `informe/`
- Informe técnico en PDF (Entrega 2 y 3)

### `mapas/`
- Mapas y planos exportados desde QGIS en formato imagen

### `notebooks/`
- Notebook de Python con desarrollo y outputs del Índice de Calidad Vial (ICV)

### `qgis/`
- Proyecto QGIS del subtramo

## Descripción
Análisis y anteproyecto de intervención vial urbana para el corredor de Avenida Lo Ovalle
en la comuna de San Miguel. Incluye diagnóstico integral, Índice de Calidad Vial (ICV)
multicriterio desarrollado en Python con OSMnx y GeoPandas, evaluación de alternativas
y propuesta de reconfiguración parcial del espacio vial.
